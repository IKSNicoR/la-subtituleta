# La Subtituleta v0.6.4 — Windows y macOS

Esta versión mejora el uso cotidiano de speakers y la calidad de los captions sin cambiar el flujo principal.

## Cambios

- Los speakers se pueden quitar individualmente y dejan de arrastrarse al trabajo siguiente.
- AssemblyAI ya no recibe una cantidad rígida de speakers: detecta las voces y devuelve confianza por palabra cuando está disponible.
- El JSON marca cifras y nombres internos con baja confianza para facilitar su revisión posterior.
- LS calibra el largo visual de los captions según el formato de la secuencia: horizontal, 4:3, cuadrado o vertical.
- Se mantienen las correcciones anteriores de Reflow, sincronía, In/Out, cortes del timeline y secuencias derivadas.

## Instalación

Descargá el ZIP correspondiente, cerrá Premiere y seguí las instrucciones incluidas. Las API keys y la biblioteca local se conservan al actualizar.

La versión macOS continúa validándose con usuarios en equipos Intel y Apple Silicon.
