# La Subtituleta v0.6.5 — Windows y macOS

Esta versión suma una forma opcional de apoyar el desarrollo desde la pantalla de Configuración.

## Cambios

- Nuevo botón **Invitame un cafecito**, enlazado al perfil oficial de Nico Russo.
- El acceso aparece debajo de la versión y se diferencia visualmente de los controles principales.
- Conserva todas las mejoras de la v0.6.4: speakers flexibles, confianza en el JSON y captions calibrados según el formato de la secuencia.

## Instalación

Descargá el ZIP correspondiente, cerrá Premiere y seguí las instrucciones incluidas. Las API keys y la biblioteca local se conservan al actualizar.

La versión macOS continúa validándose con usuarios en equipos Intel y Apple Silicon.
